Demonstration · Baseline grid

Body copy on this site is set at 16 on 24 and every vertical measurement is a multiple of eight. The red rules behind this paragraph are the baseline grid. In the unset state, the leading is 31 pixels and the paragraph spacing is 13, so the lines drift off the rules and never come back.

Press B to lock the text. Leading snaps to 24, the gap between paragraphs becomes one full line, and the measure steps down column by column until it lands on a comfortable sixty-odd characters. Lines on facing columns now align, which is the entire point.

// Every poster on this page is drawn from its title.
function seed(title) {
  let h = 0x811c9dc5;
  for (const c of title) {
    h ^= c.charCodeAt(0);
    h = Math.imul(h, 0x01000193);
  }
  return h >>> 0; // same title, same poster
}
