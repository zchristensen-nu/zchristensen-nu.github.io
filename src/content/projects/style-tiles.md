Before building this site I wanted to see the options rather than describe them. Each style tile is one self-contained HTML page that shows a direction's type, palette, textures and core components, and goes all out on interaction.

## The set

- **Eras:** a Windows 2000/XP desktop, Mac OS X Aqua, a 2006 Web 2.0 blog, a Flash-era portfolio, and a MySpace-era profile.
- **Editorial:** Swiss International Style, a modern art museum, and a broadsheet newspaper.
- **Interface:** a premium modern site, a streaming service, and five product UIs drawn from code hosting, docs workspaces, reading platforms, developer docs, and a synthesis of all three.

[Browse all fifteen](/tiles/)

The site you're reading is the direction I chose. The [write-up](/writing/fifteen-style-tiles/) explains why.
